Numlock —— 托盘数字小键盘（NumLock）状态工具（.NET 10；版本号见托盘菜单“关于”）

★ 绿色免安装：双击 Numlock.exe 直接运行（若 SmartScreen 提示，点“仍要运行”）。
★ 运行后看右下角托盘区：键帽图标 = NumLock 状态
    实心键帽   = 已开启
    描边键帽   = 已关闭
    右下角绿点 = 保持常开模式
★ 双击托盘图标：切换 NumLock（“保持常开”模式下会提示先关闭该选项）
★ 右键托盘图标：macOS 风格菜单（切换 NumLock / 保持常开 / 开机自动启动 / 图标颜色 / 检查更新 / 关于 / 退出）
★ 自动更新：启动后会自动检查新版本（菜单“检查更新”里可关闭），发现新版本会自动下载并校验，
  下载完成后在退出程序时静默替换（下次启动即新版本）；也可在菜单里选“重启并更新”立即生效。
  若上次是关机/注销结束（来不及替换），下次打开程序会自动完成替换并重启一次，无需任何操作
  （托盘图标会闪一下，属正常现象）；更新完成后会有一次“已更新到 X”的提示。
  除检查/下载更新外，本程序不进行任何网络通信（不联网、无遥测）。
★ 高 DPI 适配：菜单随所在显示器缩放自动调整，图标在缩放变化后自动重绘（100%–400%，4K / 8K 显示器适用）。
★ “保持常开”开启后：NumLock 将一直保持开启，键盘上按 NumLock 键也不会关闭它；
  如需恢复手动控制，先在菜单里取消勾选“保持常开”。
★ 已知限制：
    · 极端情况下（高权限窗口拦截等）“保持常开”会降级为约 300ms 自动纠偏（可能闪断）并气泡提示，功能不中断。
    · 程序未做数字签名，首次运行 SmartScreen 提示属正常现象；个别安全软件可能对键盘钩子给出提示。
★ 设置保存在 %AppData%\Numlock\config.json
